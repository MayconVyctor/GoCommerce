# GoCommerce

Backend de uma aplicação de e-commerce desenvolvido em Go, PostgreSQL e Docker, com foco em Domain-Driven Design (DDD) e boas práticas de desenvolvimento de software.

Em desenvolvimento.

Este projeto está sendo desenvolvido como uma prática de desenvolvimento backend com Go, aplicando conceitos e práticas utilizadas em ambientes profissionais.

##  Objetivos

O principal objetivo deste projeto é praticar:

- Go
- APIs REST
- PostgreSQL
- Docker
- Domain-Driven Design (DDD)
- Injeção de Dependência
- Interfaces e tratamento de erros
- Testes automatizados
- Git e boas práticas de desenvolvimento
